# 総合テストシート テンプレート

Excelで総合テストの計画・実施・進捗・不具合を一元管理するためのテスト管理テンプレートです。
<img width="1869" height="737" alt="image" src="https://github.com/user-attachments/assets/a4edf53c-9842-47a3-8e25-5c02adc4d055" />

テストケースの作成から実行結果の記録、不具合の修正確認、進捗状況の集計まで、ソフトウェアテストに必要な管理業務をサポートします。
Webアプリケーション、業務システム、Webサイトなど、さまざまなソフトウェア開発プロジェクトで活用できます。

## 主な特徴

- **テストケース管理**：確認内容、実施手順、期待結果を体系的に整理
- **テスト進捗管理**：実施状況や結果を集計し、進捗を可視化
- **不具合管理**：不具合の発見から修正後の再検証まで記録
- **複数環境での検証**：OS、端末、ブラウザごとにテスト結果を管理
- **テスト工数管理**：予定工数と実工数を記録
- **品質指標の管理**：テスト項目数、不具合数、不具合密度などを確認
- **レビュー管理**：テストメモやレビューコメント、対応状況を記録
- **カスタマイズ可能**：Excel形式のため、プロジェクトに合わせて項目を変更可能

## シート構成

テンプレートは、以下の6つのワークシートで構成されています。

| シート名 | 概要 |
|---|---|
| 表紙 | テスト期間、工数、進捗、結果、不具合数などを集計 |
| 環境 | テストで使用するOS、端末、ブラウザを管理 |
| テストシート | テストケース、実行結果、不具合、修正確認を管理 |
| 設定 | OS、端末、ブラウザなどの設定値を管理 |
| テストメモ | テスト内容、レビューコメント、対応状況を管理 |
| 祝日 | 休日情報を管理する補助シート |

### 1. 表紙

プロジェクト全体のテスト実施状況を把握するための管理シートです。

主な管理項目：

- テスト開始日・終了日
- 予定工数・実工数
- テスト項目総数
- テスト実施結果
- 修正済み項目数
- 未確認・保留項目数
- テスト完了率
- 不具合数・不具合密度
- テスト担当者

テストの進捗状況や品質指標を確認するために使用します。

### 2. 環境

テスト対象となる検証環境を定義します。

OS、端末、ブラウザなどを記録し、テスト実施時の環境条件を明確にします。

### 3. テストシート

テストケースの作成と実行結果を管理する中心的なシートです。

主な管理項目：

| 項目 | 説明 |
|---|---|
| No | テストケース番号 |
| 内容 | 確認する機能やテスト内容 |
| 確認手順 | テスト実施手順 |
| 期待結果 | 正常動作時に期待される結果 |
| 実施有無 | テスト対象かどうか |
| 実施者 | テスト担当者 |
| 日付 | テスト実施日 |
| 確認Ver | 検証対象のバージョン |
| CL | クライアント環境別の確認結果 |
| 検証時確認結果 | 初回検証結果 |
| バグ情報 | 不具合管理情報 |
| 最終OK日 | 最終的に正常確認できた日 |
| 修正・仕様確認結果 | 修正後の検証結果 |
| 備考 | 補足情報 |

テストケースごとに実施結果を記録することで、検証状況や修正履歴を追跡できます。

### 4. 設定

テスト環境の選択肢などを管理するシートです。

初期状態では、以下の設定値が用意されています。

| 分類 | 設定値 |
|---|---|
| OS | Windows 11、macOS、iOS、Android |
| 端末 | PC、Tablet、Moblile |
| ブラウザ | Chrome、Edge、Firefox、Safari |

※ 設定値はテンプレートに登録されている内容です。必要に応じて変更してください。

### 5. テストメモ

テスト項目の整理やレビュー結果の記録に使用します。

主な管理項目：

- シート化の有無
- テストメモ番号
- テストメモ
- レビューコメント
- レビュー議事録
- 対応内容
- 対応済みチェック

テストケース作成前の検討事項やレビューで発生した指摘事項を管理できます。

### 6. 祝日

休日情報を管理する補助シートです。

初期データには2016年の休日情報が含まれています。利用する年度に合わせて更新してください。

## テスト結果の記入方法

テスト結果は、以下の記号を使用して管理します。

| 区分 | 記号 | 説明 |
|---|---|---|
| OK | ○ | テスト結果が正常 |
| バグ | × | 新規不具合として報告 |
| 制限事項 | 制 | 開発側から制限事項との回答あり |
| 仕様確認 | 仕 | 仕様確認が必要 |
| 不要 | － | シートの誤り、環境依存など |
| 保留 | 保 | 不具合などによりテスト実施不可 |

修正後の再検証についても、専用項目で結果を管理できます。

## 使用方法

### 1. テンプレートを取得

以下のリンクからExcelファイルをダウンロードしてください。

[総合テストシート.xlsx](./総合テストシート.xlsx)

または、リポジトリをクローンします。

```bash
git clone https://github.com/mshrynzw/template_test_sheet.git
```

### 2. 検証環境を設定

「環境」「設定」シートを確認し、対象プロジェクトに合わせてOS、端末、ブラウザなどを設定します。

### 3. テスト計画を作成

「表紙」シートでテスト実施期間や予定工数などを設定します。

### 4. テストケースを作成

「テストシート」に確認内容、実施手順、期待結果などを記入します。

テストケースは、第三者が実施しても同じ結果を確認できるよう、具体的かつ再現可能な内容にすることを推奨します。

### 5. テストを実施

各テストケースについて、実施者、実施日、対象バージョン、検証結果を記録します。

不具合が発見された場合は、関連するバグ情報を記録してください。

### 6. 修正後の再検証

不具合修正後、該当するテストケースを再実行し、修正結果や最終確認日を記録します。

### 7. 進捗・品質状況を確認

「表紙」シートを確認し、テスト進捗、未確認項目、不具合数などを把握します。

## 想定する利用シーン

- Webアプリケーションの総合テスト
- 業務システムの結合・総合テスト
- Webサイトの動作検証
- リリース前の品質確認
- 不具合修正後の回帰テスト
- 複数ブラウザ・端末での動作検証
- QAチームでのテスト進捗管理

## カスタマイズ

Excel形式のため、プロジェクトの規模や開発体制に合わせて自由にカスタマイズできます。

例えば、テストケースの分類追加、確認環境の変更、担当者の追加、独自の品質指標の導入などが可能です。

ただし、集計用の数式や参照範囲が設定されているため、行・列の追加や削除を行う際は、関連する数式や集計結果に影響がないか確認してください。

## 利用上の注意事項

- テンプレートにはサンプルのテスト項目やテストメモが含まれています。実際の利用前に内容を確認してください。
- テスト期間や工数などの初期値は、利用するプロジェクトに合わせて変更してください。
- 祝日データは利用年度に合わせて更新してください。
- 一部の集計項目は、必要なデータが未入力の場合、計算エラーが表示されることがあります。
- Excelの互換ソフトでは、数式や書式が正しく再現されない可能性があります。
- 本テンプレートの利用により、ソフトウェアの品質や不具合の完全な検出を保証するものではありません。
